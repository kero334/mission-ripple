# Visual style and assets

Primary target: user-provided high-detail modern indie pixel-art Mars settlement, preserved as `project/docs/reference/visual-target.png` for comparison. Original game identity uses warm terracotta, navy/steel blue, teal, orange and metallic light surfaces. No reference screenshot is loaded at runtime. Pixel specification: 32×32 world tiles, logical 640×360 game canvas with FIT scaling, `pixelArt:true`, `roundPixels:true`, antialias disabled. Buildings are larger separate PNGs; characters use four-direction frame strips; transparent props, glows and shadows create depth. World render order uses tile layers, Y depth for structures/people, foreground details and HTML HUD. Exterior zoom 0.8, room zoom 1.

Runtime assets are in `project/public/assets/{terrain,buildings,interiors,characters,equipment,props,effects,ui,animations,atlases}`. `pixel-manifest.json` currently has **89** records (the README's 80 count is stale); each entry describes purpose, dimensions, animation frames, file and status. `asset-manifest.json` and legacy SVGs are historical. Editable high-resolution art is in `project/art-source/`. `project/tools/build_pixel_assets.py` normalizes/rebuilds pixel PNGs, sprite strips, tile/map assets and manifest; `build_science_icons.py` produces nine science icons. The runtime can use packaged PNGs without regenerating artwork. Asset production requires the Python image stack documented in tools; there is no lockfile for that stack.

To add art: retain the shared pixel grid, warm lighting and shadow direction; produce a separate transparent sprite or tile, normalize at native pixel scale, add a manifest record, check Phaser key/filename, and inspect both 720p and 1080p with nearest-neighbor rendering. Arabic uses Cairo web font with fallback; English uses VT323; offline fallback may alter appearance. Building signs are Phaser text over sprites, not integrated pixels. Terrain density, room-specific furniture/walls, strict walk-cycle registration, animation variety and bilingual bitmap typography remain open art work. See `project/docs/PIXEL_ART_SPEC.md`, `project/docs/UNFINISHED.md`, and `project/qa-screenshots/`.
