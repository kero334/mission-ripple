# Gameplay systems

The player starts outdoors at `(640,595)` in a connected nine-building outpost. Facilities are `habitat`, `power`, `greenhouse`, `water`, `research`, `comms`, `command`, `shelter`, `oxygen` in `src/world-data.ts`. Buildings are individual sprites with door targets and collision rectangles; each enters an illustrated 640×360 room. Each room has an E-interactive equipment target and an exit. Exterior field terminal at `(664,690)` begins mission evidence. All nine rooms are accessible, but only the Research/Command/Communications equipment participates in P2-M02.

`MarsScene.update` reads WASD/arrows, normalizes diagonal movement, uses speed 92 or Shift sprint 132 world units/sec, changes four-direction astronaut frames every ~130 ms, updates depth and Nuri following. `interact` handles door/exit/Nuri/equipment/field, briefly sets interaction frame, and emits an event for science UI. Collision uses Phaser geometric rectangles; priority objects and buildings use Y-based depth sorting. Camera follows smoothly; see architecture. Scene pause state blocks movement and interaction while DOM overlays are open.

The HUD offers objective list, current destination, interaction prompt, inactive resource status, Nuri dialogue, toolbar, map, journal, inventory preview and settings. M/J/B/Esc/L are shortcuts; the toolbar preview does not use items. Main HUD orientation checklist reflects world state, but the science UI overrides it while mission active. Map is a facility list, not a spatial map. Journal displays mission stage and choice; it is not a discovery archive.

To extend, register new interaction targets in `scene.ts`, use stable facility ID and target kind, consume `ripple-world-interaction` in a mission controller, and drive HUD state from deterministic data. New physical resources require approved models; the existing resource panel intentionally displays dashes. Relevant QA: `tools/camera-qa.mjs`, `tools/science-qa.mjs` and archived results; old `tools/playtest.mjs` and `tools/pixel-pass1.mjs` target obsolete UI.
